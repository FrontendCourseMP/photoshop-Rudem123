# Технологии компьютерной графики

> **Демо:** https://photoshop-rudem123.onrender.com/

Веб-приложение для обработки изображений (аналог Photoshop), написанное на React + TypeScript + Vite.

## Возможности

### Форматы файлов
- Загрузка PNG, JPG, JPEG и кастомного формата **GB7**
- Экспорт в PNG, JPG, GB7 (с маской и без)

### Уровни (Levels)
- Коррекция яркости через входные/выходные уровни
- Гистограмма по каналам
- Предпросмотр в реальном времени

### Масштабирование
- Собственная реализация **билинейной интерполяции** и метода **ближайшего соседа**
- Автоподгонка изображения при загрузке (с отступами 50px)
- Ползунок масштаба 12%–300% в статус-баре
- Модальное окно «Размер изображения» с валидацией, пропорциями и выбором алгоритма

### Фильтры (Свёртка)
- Ядро свёртки 3×3 с редактируемой сеткой
- Пресеты: тождественное, резкость, Гаусс, прямоугольное размытие, оператор Прюитта (2 варианта)
- Выбор каналов (R, G, B) для применения фильтра
- Стратегии обработки краёв: чёрный, белый, копирование
- Предпросмотр в реальном времени

### Инструменты
- Пипетка с конвертацией RGB → LAB
- Панель каналов с миниатюрами

## Структура проекта

```
src/
├── App.tsx                          # Главный компонент
├── App.css                          # Стили интерфейса
├── utils/
│   ├── gb7.ts                       # Кодек GB7
│   ├── interpolation.ts             # Билинейная + ближайший сосед
│   └── convolution.ts               # Свёртка с ядром 3×3
└── components/
    ├── LevelsDialog.tsx             # Диалог «Уровни»
    ├── ResizeDialog.tsx / .css       # Диалог «Размер изображения»
    └── ConvolutionDialog.tsx / .css  # Диалог «Фильтр (Свёртка)»
```

## Запуск

```bash
npm install
npm run dev
```
