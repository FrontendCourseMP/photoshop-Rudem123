# Технологии компьютерной графики — Лабораторная работа №1

## Обработка изображений и кастомный формат GB7

Данный проект посвящен разработке и исследованию алгоритмов кодирования и декодирования изображений с использованием специализированного формата **GB7**.

### Особенности формата GB7
Формат **GB7** оптимизирован для эффективного представления полутоновых (черно-белых) изображений с поддержкой 1-битной прозрачности (маски альфа-канала):
* **Сигнатура файла:** `GB7\x1D` (байты `0x47`, `0x42`, `0x37`, `0x1D`).
* **Версия формата:** 1 байт (`0x01`).
* **Флаги:** 1 байт (младший бит определяет наличие маски альфа-канала).
* **Размеры:** Ширина и высота изображения записываются как 2-байтовые целые числа в формате Big-Endian.
* **Данные пикселей:** Каждому пикселю соответствует 1 байт:
  - 7 младших бит кодируют оттенок серого (`0-127`), который при чтении масштабируется в стандартный диапазон `0-255`.
  - Старший бит (при наличии флага маски) отвечает за прозрачность (0 — прозрачный, 1 — непрозрачный).

### Функционал приложения
1. **Загрузка файлов:** Поддержка стандартных веб-форматов (`.png`, `.jpg`, `.jpeg`), а также чтение и декодирование кастомных файлов `.gb7`.
2. **Экспорт:**
   - Сохранение в стандартные форматы (`PNG`, `JPG`).
   - Кодирование в формат `GB7` без маски (всегда 100% непрозрачность).
   - Кодирование в формат `GB7` с маской (прозрачность определяется по альфа-каналу исходного изображения).
3. **Панель состояния:** Отображение метаданных загруженного изображения (ширина, высота, глубина цвета).

### Структура проекта
* `src/App.tsx` — Основной интерфейс приложения, обработка событий загрузки, отрисовки на `HTML5 Canvas` и скачивания.
* `src/utils/gb7.ts` — Реализация низкоуровневых алгоритмов кодирования (`encodeGB7`) и декодирования (`decodeGB7`) на основе `ArrayBuffer` и `DataView`.
